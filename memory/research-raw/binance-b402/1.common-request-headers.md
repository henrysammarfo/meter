# Common API request headers

| Parameter               | Description                                                                         | Mandatory | Remarks                                                |
| ----------------------- | ----------------------------------------------------------------------------------- | --------- | ------------------------------------------------------ |
| Content-Type            | application/json                                                                    | Yes       |                                                        |
| X-Tesla-ClientId        | Partner (client) id provided by B402                                                | Yes       |                                                        |
| X-Tesla-SignAccessToken | Access token provided by B402                                                       | Yes       |                                                        |
| X-Tesla-Signature       | A signature generated by request body, timestamp and partner (client) private key\* | Yes       | Refer to "[API Request signing](3.request-signing.md)" |
| X-Tesla-Timestamp       | Timestamp in millisecond                                                            | Yes       |                                                        |

> \*_The private key and public key are generated by the partner (client). Please refer to
> "[API Request signing](3.request-signing.md)" for the generation method._
